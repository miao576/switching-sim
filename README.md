# 综合交换网络与程控交换仿真平台

基于 Python 标准库实现的综合教学仿真平台，深度融合了《交换单元与组网》与《数字程控电话交换》的核心知识点。
项目从底层的 PCM 时隙交换、空间交换，一路打通到上层的用户电路（BORSCHT）与呼叫状态机（FSM），完整复现了一次本局电话呼叫的“摘机 → 拨号 → 振铃 → 通话 → 拆线”全流程。

## 🏗️ 分层架构与知识点

项目采用严格的分层架构，自底向上分为四大层：

### 1. 核心数据与信号层 (`core/`)
| 模块 | 对应知识点 |
| :--- | :--- |
| `pcm_frame.py` | G.704 基本帧、16帧复帧、FAS同步码、TS0/TS16分配 |
| `signal_tones.py` | 交换系统音频信号发生器（拨号音、忙音、回铃音等） |

### 2. 交换网络硬件层 (`units/` & `networks/` & `analysis/`)
| 模块 | 对应知识点 |
| :--- | :--- |
| `time_switch.py` | T接线器：共享存储器型、顺写控读/控写顺读两种模式 |
| `space_switch.py` | S接线器：三维时空交叉矩阵（支持时隙复用）、单播约束 |
| `tst.py` | TST三级网络：**动态自动寻路**、**反相法**（半帧差）双向时隙分配、并发阻塞控制 |
| `dsn.py` | DSN网络：两级自选路由、选择/数据/置闲信道字 |
| `clos.py` | CLOS网络：严格无阻塞 (m≥2n−1) / 可重排无阻塞 (m≥n) 验证 |
| `blocking.py` | Lee 模型：三级网络阻塞概率数学分析 |

### 3. 接口设备层 (`interfaces/`)
| 模块 | 对应知识点 |
| :--- | :--- |
| `user_circuit.py` | 模拟用户电路 BORSCHT：摘挂机状态扫描（边沿检测）、馈电、振铃控制 |

### 4. 控制软件大脑层 (`control/`)
| 模块 | 对应知识点 |
| :--- | :--- |
| `call_state_machine.py` | 呼叫状态机（FSM）：状态迁移、号码分析、选路指令下发、资源申请与释放 |
